# Security Policy

## Supported versions

Fablesheet is pre-1.0. Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/fablesheet/fablesheet/security/advisories/new).

Please include a description of the issue, steps to reproduce, and the affected version. You can expect an initial response within 7 days.
